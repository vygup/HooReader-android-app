# HooReader

Нативная Android-читалка EPUB и FB2 на Kotlin и Jetpack Compose. Импортирует выбранный файл
в собственное локальное хранилище, показывает библиотеку и сохраняет место чтения.
Минимальная версия Android — 8.0 (API 26).

Первый выпуск — **1.0.0**. [Release notes](docs/releases/1.0.0.md) ·
[Сборка подписанного APK/AAB и выпуск](docs/releasing.md).
Для release-сборки: `python3 scripts/build-release.py`.

Текущий локальный RC — **2.0.0**, versionCode 2; команды сборки создают именно его.
[Изменения RC](docs/releases/2.0.0.md) ·
[Комплект APK/AAB и его проверка](docs/releases/2.0.0-validation.md) ·
[Итоги проверок](specs/002-reader-appearance/validation-results.md) ·
[Матрица требований](specs/002-reader-appearance/evidence/validation-summary.json).
RC пока не принят: открыта аппаратная производительность SC-004. T062/SC-007 пройдена
по подтверждению пользователя. Instrumentation на API 26 и API 37 пройден.

## Возможности

- Импорт EPUB без DRM и FB2 через стандартный Android File Picker.
- Библиотека с названием, автором, обложкой или заглушкой и примерным прогрессом.
  При отсутствии metadata используются имя файла и «Неизвестный автор»; от 98% — «Прочитано».
- Повторный импорт того же содержимого сохраняет прежнюю запись и позицию чтения.
- Вертикальное чтение абзацев, заголовков, bold/italic, базовых списков и растровых изображений;
  переход по содержанию и главам.
- Постраничное чтение со свайпом на одну страницу и сохранением логического места
  при смене режима, размера текста и ориентации. Режим общий для всех книг.
- Панели управления появляются и скрываются одиночным касанием области книги;
  при скрытых панелях остаются глава и минимальный указатель положения.
- Сохранение логической позиции: глава, блок, смещение. Прогресс записывается с debounce 400 ms
  и принудительно при выходе/остановке; восстановление выбирает ближайший существующий блок.
- Светлая/тёмная тема и размер текста 75–200%, настройки сохраняются на устройстве.
- Настройки чтения применяются автоматически; меню закрывается действием «Назад».
  Подтверждение выхода из книги включено по умолчанию и отключается в настройках приложения.
- Удаление после подтверждения удаляет локальную копию, metadata и прогресс; исходник остаётся.

После успешного импорта книга доступна без интернета даже после удаления или переноса исходного
файла. Книги, Room-база и DataStore preferences находятся во внутреннем хранилище приложения.
У приложения нет разрешений на интернет или широкий доступ к накопителю; backup отключён.
Удаление приложения удаляет его локальные данные; функции экспорта/синхронизации в MVP нет.

## Сборка

Требуются JDK 17–21, Android SDK API 36 и Build Tools 35.0.0. Укажите путь SDK через `ANDROID_HOME`
или `sdk.dir` в локальном `local.properties` (этот файл не включается в Git).
Gradle 8.14.3 установлен через Wrapper; AGP/Kotlin/зависимости закреплены в проекте.
Первой сборке нужен интернет для загрузки инструментов и зависимостей; чтение импортированных
книг не зависит от доступа к сети.

```sh
./gradlew :app:assembleDebug
./gradlew :app:installDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. Для установки требуется подключённое устройство
или запущенный Android emulator. Подробнее: [docs/building.md](docs/building.md).

## Проверки

```sh
./gradlew :app:check :app:assembleDebug :app:assembleDebugAndroidTest
./gradlew :app:connectedDebugAndroidTest
```

`check` запускает unit tests, Detekt и Android Lint. UI-тестам нужен включённый и разблокированный
экран. В общем прогоне process-death и performance tests штатно пропускаются: для них нужны
отдельные режимы запуска. Корпус импорта проверяется и в общем instrumentation-прогоне.
Для отдельного воспроизведения после сборки обоих debug APK:

```sh
export ADB="$ANDROID_HOME/platform-tools/adb"
export ANDROID_SERIAL=emulator-5554
scripts/verify-reader-process-death.sh
scripts/verify-reader-font-scale.sh
scripts/measure-reader-performance.sh /tmp/hooreader-performance.json
scripts/verify-import-corpus.sh /tmp/hooreader-import-corpus.json
```

Матрица системного шрифта 100/150/200%, двух масштабов чтения, двух форматов,
режимов, тем и ориентаций проверена на API 37 (96 сочетаний). Полный общий прогон:
48 выполненных UI tests и 17 opt-in skipped на каждом из API 26 и API 37;
последние требуют отдельных scripts. После исправлений совместимости тестового
ввода и screenshot повторены четыре затронутых теста на API 37 — без ошибок.
Performance script при отсутствии физического устройства записывает
`NOT_VERIFIED_DEVICE`. Эмуляторная диагностика запускается с `--allow-emulator --ui-only`
и не подтверждает аппаратные пороги. Подписанное обновление v1 → v2 проверяет
`python3 scripts/verify-reader-upgrade.py` только во временном `-read-only` emulator.

Process-death script предназначен для эмулятора: завершает процесс приложения между фазами,
временно включает авиарежим и восстанавливает его прежнее состояние. Performance script
использует отдельные UI samples и production pagination series; старый первый протокол
доступен с `--legacy`. Тесты удаляют свои записи и возвращают прежние настройки.
Скрипты корпуса/performance используют `run-as` и предназначены для debug сборки.
Fixtures синтетические; `python3 scripts/generate-import-corpus.py` воспроизводит corpus v1.

Исторические результаты первого релиза, Phase 7 на Pixel_10 AVD / API 37:

- По 56 unit tests debug/release; UI, восстановление после завершения процесса и авиарежим —
  без ошибок в перечисленных сценариях.
- Corpus v1: 17/17 допустимых книг импортированы, открыты все 34 главы; 7/7 ошибочных файлов
  отклонены. Это синтетический baseline, не гарантия всех EPUB/FB2.
- FB2 20 MB: открытие 1,18–1,33 s в трёх запусках на эмуляторе после импорта.
- Порог ≥95% кадров ≤16,7 ms не пройден в измерении FrameMetrics на этом стенде.
  Приёмка производительности на физическом Android среднего класса остаётся неподтверждённой.

## Ограничения offline MVP

EPUB с DRM не импортируются. EPUB 2/3 и FB2 преобразуются в общий набор блоков;
сложная CSS-вёрстка, fixed layout, SVG, интерактивность и внешние media не поддерживаются.
Нечитаемое изображение/фрагмент заменяется заглушкой, когда остальной текст доступен.
PDF, DJVU, MOBI и AZW3 не поддерживаются.

Аккаунтов, облака, сетевых каталогов и синхронизации нет. **OPDS запрещён в scope текущего MVP**:
его реализация требует отдельной Feature Specification с утверждёнными требованиями к каталогам,
аутентификации, секретам и offline-поведению согласно конституции проекта.

Security review первого релиза выявил отсутствие явных лимитов размера/распаковки/времени
импорта и очистки осиротевших файлов после аварийного завершения процесса. Полная проверка
TalkBack и репрезентативного внешнего корпуса остаётся невыполненной. Матрица
системного шрифта второго RC проверена отдельно, как описано выше. TalkBack исключён
из текущей матрицы согласованным решением; это не означает его проверку.
