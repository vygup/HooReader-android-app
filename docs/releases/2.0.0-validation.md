## Проверки точного APK

Новый APK имеет другую контрольную сумму относительно предыдущего RC.
Проверки обновления и smoke повторены и прошли на этом файле на одном временном
read-only эмуляторе Pixel_10 API 37 arm64-v8a:

- Установка подписанного 1.0.0, заполнение библиотеки EPUB/FB2, обновление до 2.0.0
  без очистки данных между версиями. Проверяются восстановление второй главы
  при отсутствии первой в viewport, тема DARK, масштаб 150%, оба режима офлайн.
- Отдельная установка 2.0.0 и внешний UI smoke: настоящий File Picker, оба
  формата, настройки, глава, завершение процесса, повторное открытие в авиарежиме,
  удаление записи при сохранении исходного файла.

Фактические результаты и SHA-256 проверенного APK:
[upgrade/summary.json](../../specs/002-reader-appearance/evidence/upgrade/summary.json),
[release/summary.json](../../specs/002-reader-appearance/evidence/release/summary.json).
Данные постоянного AVD не изменяются.

## Комплект для передачи

`scripts/package-release.py` сверяет SHA-256 сборки с успешными smoke/upgrade,
проверяет содержимое ZIP после записи и формирует:

- `app/build/release/2.0.0/HooReader-2.0.0-release.zip`;
- `app/build/release/2.0.0/HooReader-2.0.0-release.zip.sha256`.

В архиве ровно шесть файлов: APK, AAB, `SHA256SUMS.txt`, `RELEASE_NOTES.md`,
`INSTALLATION.md`, `RELEASE_MANIFEST.json`. Manifest содержит SHA-256 пяти
остальных файлов, исходный коммит, сертификат и условия приёмки.
Ключи, пароли и служебные test outputs в комплект не включены.
Проверка CRC, точного состава, SHA-256 каждого файла manifest и двух внешних
файлов checksums пройдена. Публичные копии manifest и checksum архива находятся в
[evidence/release](../../specs/002-reader-appearance/evidence/release/).

## Условия приёмки

T062/SC-007 пройдена по подтверждению пользователя. Остальные технические
проверки перечислены в [матрице FR/SC](../../specs/002-reader-appearance/evidence/validation-summary.json).
SC-004 остаётся открытым: полная серия на физическом устройстве отсутствует,
прежние замеры 20 MB не прошли порог ≤1 секунды. Подготовка архива не меняет
результат этой метрики. Manifest сохраняет `releaseAccepted: false` и статус
`RC_PENDING_ACCEPTANCE` до решения по этому условию.
