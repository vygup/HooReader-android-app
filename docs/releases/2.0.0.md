# HooReader 2.0.0 — локальный RC

versionCode 2. Собран 2026-10-07, подписанное обновление и внешний smoke проверены
2026-10-09 на API 37 emulator. **Релиз не принят и не опубликован.**
Общий набор совместимости прошёл на API 26 и API 37; исправлены два ограничения
тестового инструмента на старом Android, повторены затронутые тесты на API 37.

Добавлены скрываемые касанием панели, вертикальный и постраничный режимы,
минимальные указатели главы и положения, автоматически сохраняемые настройки
чтения и отключаемое подтверждение выхода. Содержание и настройки закрываются
одним действием «Назад», в том числе при раскрытом меню и большом системном шрифте.
Оба режима читают импортированные EPUB/FB2 без интернета. Room schema остаётся v1.

Подписанное обновление с 1.0.0 сохраняет библиотеку, главу, тему и масштаб.
Проверены 26 файлов корпуса, process death с отсутствующим производным кэшем,
96 сочетаний размера шрифта/режима/темы/ориентации, debug unit/static/UI checks
и внешний smoke настоящего release APK. Подпись первого выпуска сохранена.

Открытые условия приёмки:

- SC-004: физического стенда нет; полная серия RC по performance-protocol не проведена.
  Прежние 20 MB замеры не прошли порог ≤1 секунды; это release blocker.
- SC-007: исследование с пятью участниками не проведено.
