# HooReader 1.0.0

Первая версия офлайн-читалки EPUB и FB2 для Android 8.0 и выше.

## Возможности

- Импорт EPUB без DRM и FB2 через системный выбор файлов.
- Собственная локальная копия книги: чтение работает без интернета и после удаления исходника.
- Библиотека с обложками/заглушками, метаданными и примерным прогрессом; защита от повторного импорта.
- Вертикальное чтение абзацев, заголовков, bold/italic, списков и растровых изображений.
- Содержание и переход между главами, сохранение и восстановление логической позиции.
- Светлая/тёмная тема, размер текста 75–200% и сохранение настроек.
- Подтверждение удаления локальной книги; исходный файл пользователя сохраняется.
- Адаптивная иконка открытой книги, включая монохромный вариант Android 13+.

## Файлы выпуска

- `HooReader-1.0.0.apk` — подписанная release-сборка для прямой установки.
- `HooReader-1.0.0.aab` — подписанный Android App Bundle для подготовки публикации в магазине.
- `SHA256SUMS.txt` — контрольные суммы APK/AAB.

Версия: `1.0.0`, versionCode: `1`, package: `com.hooreader`, minSdk: `26`, targetSdk: `36`.
APK подписан отдельным release-ключом и не содержит debug test Activity/Provider.
APK/AAB не содержат приватного ключа или пароля подписи.

## Проверка и известные ограничения

В Phase 7 прошли unit/UI-тесты и offline/process-death сценарии. Синтетический corpus v1:
17/17 допустимых книг, 34/34 главы и 7/7 ожидаемых отказов. Для релизного APK дополнительно
проверены оба формата через настоящий системный File Picker, новая подпись, non-debuggable
режим, перезапуск, авиарежим, настройки и удаление без удаления оригинала.

Оценка плавности ≥95% кадров ≤16,7 ms на эмуляторе **не пройдена**. Приёмка производительности
на физическом Android среднего класса, TalkBack/все системные масштабы и отдельный прогон API 26
остаются неподтверждёнными. Эти результаты не объявляются гарантиями для всех устройств и книг.

Из security review остаются открытыми явные лимиты размера/распаковки/времени импорта и очистка
осиротевших файлов после аварийного завершения процесса. Пользователю рекомендуется импортировать
знакомые локальные книги; аудит намеренно вредоносного corpus не выполнен.

EPUB с DRM, PDF/DJVU/MOBI/AZW3, сложная CSS/fixed layout, SVG и активные/внешние media не поддерживаются.
Отдельные нечитаемые фрагменты заменяются заглушками. OPDS, сеть, аккаунты, облако и синхронизация
не входят в эту версию. Удаление приложения удаляет его локальную библиотеку; экспорта/backup нет.

Предыдущие debug APK имеют другую подпись и не обновляются этим APK поверх установленной debug-версии.
Удаление debug-версии удаляет её локальные данные; перед такой миграцией сохраните исходные книги.
