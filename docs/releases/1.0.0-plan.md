# Подготовка первого релиза HooReader 1.0.0

Запрос пользователя: выпустить первую версию после Phase 7. Версия приложения — 1.0.0,
versionCode — 1, applicationId — com.hooreader, Android API 26+. Scope остаётся offline MVP.

## Требования к выпуску

- Выпуск содержит подписанные release APK для прямой установки и AAB для подготовки к магазину.
- Release подписывается отдельным долговременным ключом; debug certificate не используется.
- Подпись поступает из environment variables; приватный ключ и пароль не включаются в Git,
  APK/AAB, release notes или диагностические отчёты.
- При отсутствии существующего ключа создаётся локальное PKCS12-хранилище с правами 600
  в игнорируемом каталоге `.signing/` с правами 700. Для будущих обновлений сохраняется тот же ключ.
- У приложения появляется адаптивная иконка открытой книги; основной UX не изменяется.
- Release APK проверяется на Android emulator, включая импорт и локальное повторное открытие.
- Артефакты имеют SHA-256 checksums, release notes и отчёт проверки.
- Release notes явно содержат известные ограничения Phase 7: performance acceptance на физическом
  устройстве не подтверждена, frame threshold на эмуляторе не пройден, corpus синтетический;
  замечания security/UX review не объявляются исправленными.
- Публикация не должна утверждать прохождение всех release acceptance criteria. При недоступной
  GitHub-авторизации полностью готовые артефакты и tag остаются локальными; публикация не имитируется.
