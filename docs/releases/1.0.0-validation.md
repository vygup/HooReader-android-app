# Проверка HooReader 1.0.0

Дата: 2026-10-01. Результат: подписанные локальные APK/AAB подготовлены и проверены.
Публикация GitHub Release и rollout магазина не выполнены: SSH/HTTPS-авторизация недоступны,
управление открытой Safari-сессией вернуло `Computer Use permissions are not granted`.

## Артефакты и подпись

Package `com.hooreader`, versionName `1.0.0`, versionCode `1`, minSdk `26`, targetSdk `36`.
Сборка release, non-debuggable. APK имеет APK Signature Scheme v2; apksigner verification — PASS.
AAB: jarsigner verification — PASS; оба артефакта подписаны одним сертификатом.

- Subject: `CN=HooReader release`.
- RSA: 3072 bits, validity: 10000 days.
- SHA-256 certificate: `c0070284e6b608c54a4daaf1687a4287fe6cc0ade5669b8639b68fda4ad771ca`.
- Приватный ключ/пароль: только игнорируемый `.signing/`, права 600/600; каталог — 700.
- Debug Activity/Provider, INTERNET и широкие storage permissions в release manifest отсутствуют.
  Есть только signature permission AndroidX dynamic receiver; allowBackup=false.
- Test corpus не включён в APK. Добавлена adaptive book icon / monochrome API 33+.

Именованные файлы, окончательные SHA-256 и результаты verification:
`app/build/release/1.0.0/`. Checksum APK/AAB не включён в этот документ, чтобы пакет можно было
пересобрать из окончательного tag без циклической зависимости commit → APK hash → commit.
Источник конкретного APK проверяется по packaged version-control metadata и локальному tag.

GPU host Apple M3. Release smoke выполнен в `-read-only` overlay: постоянные данные исходного
AVD не меняются. `release-smoke.txt`, UI XML и PNG сохраняются рядом с APK; в публичный архив
включаются только APK/AAB, checksums и notes.

Во время проверки обнаружена гонка cleanup существующего LibraryViewModelTest: resetMain
выполнялся одновременно с завершением Room observer. После store.clear тест теперь ждёт
завершения ViewModel scope Job перед resetMain; unit-проверки прошли. Код reader/library
в main sources не изменялся. Smoke driver обновляет accessibility node после переходов и
проверяет checked state на RadioButton container; исходные файлы дополнительно проверяются
на host через SHA-256.

## Границы выпуска

Этот отчёт не отменяет ограничения Phase 7: frame threshold на эмуляторе не пройден;
performance acceptance на физическом устройстве среднего класса, API 26/TalkBack/system scales
и представительный внешний corpus не подтверждены. Замечания security review к лимитам импорта
и recovery не исправлялись. Ограничения включены в [release notes](1.0.0.md).
