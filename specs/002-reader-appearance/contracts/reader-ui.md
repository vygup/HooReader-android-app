# UI-контракт: читалка и настройки второго релиза

**Основание**: [спецификация](../spec.md), [модель данных](../data-model.md).
Контракт описывает события приложения; сетевого API эта функция не создаёт.

## Поверхности и геометрия

LibraryScreen предоставляет переход в AppSettingsScreen.
ReaderDestination содержит BookViewport, постоянные ReadingIndicators, независимый overlay
ReaderControls и ровно одно модальное окно. ReaderViewModel — владелец состояния чтения и chrome.

В скрытом состоянии:
- VERTICAL: сверху глава и целый процент; снизу дополнительного показателя нет.
- PAGINATED: сверху глава, снизу глобальный pageNumber начиная с 1; процент отсутствует.

Обе полосы остаются вне области текста; постраничные панели располагаются поверх книги,
без изменения её размера или page slices. Открытые панели предоставляют выход, настройки,
содержание и применимые переходы между главами. Модальные события не проходят к жестам книги.
Тема меняет цвета; при неизменных метриках её выбор не пересчитывает страницы.

## События читателя

| Событие | Предусловие | Обязательный результат |
|---|---|---|
| BookOpened(bookId) | READY книга | выбранный режим и прежний anchor; скрытые панели |
| BookTap | Reading, overlay=NONE, не drag | toggle панелей; страница и anchor неизменны |
| DragStarted | область книги, touch slop достигнут | скрыть панели; tap подавлен до завершения/отмены |
| DragCancelled/DragReleased | тот же gesture | панели не открывать |
| SwipeLeft/SwipeRight | PAGINATED | одна следующая/предыдущая settledPage |
| BoundarySwipe | первый/последний page при известном EOF | оставить страницу, не выйти из книги |
| PageFrontierRequested | EOF ещё неизвестен | подготовить следующий фрагмент, не считать книгу законченной |
| ScrollPositionChanged(anchor) | VERTICAL | обновить позицию/главу/процент и сохранить |
| PageSettled(anchor) | PAGINATED, актуальная generation | сохранить начало новой страницы |
| ContentsRequested | применимо содержание | overlay=CONTENTS |
| ChapterSelected(index) | доступная глава | flush, открыть начало главы в режиме; скрыть панели и menu |
| ReaderSettingsRequested | книга открыта | overlay=READER_SETTINGS |
| OverlayDismissed | menu открыт | закрыть menu, скрыть панели, сохранить выбранные параметры |
| GeometryChanged(key) | режим/масштаб/system font/viewport | сохранить anchor, отменить старый расчёт, восстановить его в новой геометрии |
| ReaderStopped | уход в фон/системное прерывание | flush; запрос выхода отсутствует |

Чистый tap завершается после отпускания; событие consumed дочерней кнопкой/scroll/pager
не преобразуется в BookTap. Незавершённое перемещение не листает страницу и не открывает панели.
Не меняющий положение boundary drag всё равно скрывает видимые панели.

При переключении режима сохраняемый restoreAnchor остаётся исходным до новой явной навигации.
Одно касание не вызывает повторное создание layout. Во время PreparingPages показывается
признак подготовки; глобальный номер не подменяется локальным, старым или приблизительным.
Выход доступен; невозможные жесты не ставятся в очередь на неожиданное перелистывание позже.

## Настройки чтения и приложения

| Событие | Результат |
|---|---|
| ReadingModeSelected(VERTICAL/PAGINATED) | requested режим; сохранить позицию перед сменой геометрии, затем apply/write |
| FontScaleSelected(value) | конечное значение 0,75–2,0; slider применяет при отпускании |
| ThemeSelected(LIGHT/DARK) | автоматически применить и сохранить |
| PreferencesWriteFailed(fields) | пометить все актуальные pending поля; понятная ошибка и retry |
| PreferencesRetryRequested | повторить актуальные pending значения последовательно |
| AppSettingsRequested | отдельный маршрут из библиотеки |
| ConfirmReaderExitChanged(value) | автоматическое применение и сохранение общего preference |

ReaderSettingsSheet содержит тему, масштаб и выбор режима рядом с масштабом, без «Готово».
Закрытие: Back, tap снаружи или жест закрытия. Меню прокручивается; ошибка остаётся видимой,
пока есть несохранённые поля. Последующая успешная запись другого поля её не очищает.

AppSettingsScreen содержит «Подтверждать выход из книги»; default true.
Неудача записи показывает pending состояние; после перезапуска применяется сохранённое значение.
При IO-ошибке flush перед сменой геометрии старое место и effective layout остаются до retry.

## Выход и порядок Back

| Контекст | Действие Back |
|---|---|
| Открыт ReaderSettingsSheet или содержание | закрыть menu, скрыть панели |
| Открыт «Выйти из книги?» | отменить запрос, оставить прежнее чтение |
| Книга без модальных окон, защита включена | показать запрос |
| Книга без модальных окон, защита отключена | начать сохранение и выход |
| SAVING | не создавать второй запрос или второй navigate effect |

Запрос: «Выйти из книги?»; действия «Продолжить чтение» и «Выйти».
Back или tap снаружи эквивалентны продолжению. «Выйти» вызывает flushPosition;
NavigateToLibrary возникает ровно один раз после успеха. Ошибка оставляет книгу открытой
с возможностью повторить сохранение/выход. Reader BackHandler включён только при отсутствии
модальности; Dialog/BottomSheet обеспечивают собственный dismiss.

## Указатели, состояние загрузки и крупный шрифт

Глава соответствует первому видимому фрагменту. Без названия — «Глава N»; без разделов поле
отсутствует. Длинное название сокращается с ellipsis; содержание сохраняет полное название.
Процент 0..100 относится к книге, конец содержимого — 100. Номер страницы соответствует LayoutKey.

Opening и PreparingPages показывают подготовку; RecoverableError предлагает повтор и выход.
Сообщения сохранения не блокируют доступное содержимое. Обработчик открытия не публикует Reading
с невалидными page boundary или неготовым точным номером.

Все тексты используют sp и системное преобразование Compose; при 100/150/200% обеспечиваются
переносы действий, прокрутка меню, читаемые указатели и отсутствие перекрытия в обеих ориентациях.
TalkBack отложен по ответу B. Системные status/navigation bars остаются в границах исходного scope.

## Наблюдаемые идентификаторы для instrumentation

Сохранить reader_screen и reader_list для вертикального режима. Новые tags:
reader_viewport, reader_controls, reader_chapter_indicator, reader_progress_indicator,
reader_page_indicator, reader_pager, reader_open_contents, reader_open_settings, reader_exit,
reading_mode_vertical, reading_mode_paginated, app_settings, confirm_reader_exit,
reader_exit_dialog, reader_continue_reading, reader_confirm_exit, reader_preparing_pages.

Программные callbacks имеют семантические события выше; tags служат автоматизации и
не показывают пользователю детали реализации.
